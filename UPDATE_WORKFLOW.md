# SUR18 weekly inventory review

This private Site uses EIA-860M Operating_PR as its canonical source. The latest validated snapshot lives in D1. The server discovers the newest monthly workbook at https://www.eia.gov/electricity/data/eia860m/, imports Operating_PR and preserves the previous snapshot when validation fails. Batteries are separate from generation.

For unattended updates, retrieve this Site with get_site. Obtain supported service access. Discover the newest monthly Excel file on https://www.eia.gov/electricity/data/eia860m/ and download it in the cloud task, since EIA may return HTML to hosting servers. POST the binary workbook to /api/import?period=YYYY-MM&source=URL_ENCODED_EIA_XLSX_URL on current_live_url using Content-Type application/octet-stream and the returned service credential in the OAI-Sites-Authorization header. Never log or save credentials. Then GET /api/inventory using the same service access and verify checkedAt, period, unique plant count, generator count and capacities. The import endpoint validates the official origin, workbook signature, Operating_PR sheet, period monotonicity and expected plant count before storing. If there is no newer monthly edition, re-import the current official workbook to record the weekly review. Preserve data if downloading or validation fails. This Site remains owner-private; both paths rely on the Sites access boundary.

Run weekly on Mondays at 09:00 America/La_Paz. EIA publishes monthly; a successful weekly review may leave the data period unchanged. Do not re-publish the Site for data-only updates. Report failures requiring action; stay quiet when there is no new source edition. Never substitute OpenInfraMap or infer missing capacity values.
